# MARTPOS

Offline Mart POS & Inventory Management Desktop Application for Windows.

## Requirements

- Node.js 20+
- npm 10+
- Windows 10/11 (target platform)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Package (Windows Installer)

```bash
npm run package
```

Output: `release/MARTPOS-Setup-x.x.x.exe`
